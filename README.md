# Eileen Farnham portfolio

Static portfolio website ready for GitHub Pages.

## Publish on GitHub Pages
1. Upload all files and the `assets` folder to the root of your GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.
5. GitHub will show the public Pages address once deployment finishes.
